# SOLID Principles and Legacy Code Refactoring

## Proje Hakkında

Bu proje, Nesneye Dayalı Programlama (OOP) kapsamında SOLID tasarım prensiplerinin mevcut yazılım sistemlerinin yeniden düzenlenmesindeki rolünü incelemek amacıyla hazırlanmıştır.

Çalışmanın temelini, 2025 yılında *Journal of Systems and Software* dergisinde yayımlanan **"Applying SOLID Principles for the Refactoring of Legacy Code: An Experience Report"** başlıklı akademik makale oluşturmaktadır.

## İncelenen Makale

- **Yazarlar:** Ivan Yanakiev, Bogdan-Mihai Lazar, Andrea Capiluppi
- **Yayın yılı:** 2025
- **Dergi:** Journal of Systems and Software
- **DOI:** https://doi.org/10.1016/j.jss.2024.112254

## Araştırmanın Kapsamı

Makale, ASML şirketinde kullanılan büyük ölçekli C++ tabanlı bir yazılım sistemindeki mimari bağımlılıkların ve teknik borcun azaltılmasına yönelik gerçekleştirilen bir çalışmayı ele almaktadır.

Bu proje kapsamında özellikle şu kavramlar incelenecektir:

- SOLID tasarım prensipleri
- Dependency Inversion Principle (DIP)
- Legacy Code (Eski Kod Sistemleri)
- Refactoring (Kodun Yeniden Düzenlenmesi)
- Architectural Technical Debt (Mimari Teknik Borç)

Makalenin araştırma yöntemi, elde edilen bulgular ve önerilen yaklaşımlar nesneye dayalı programlama açısından değerlendirilecektir.
